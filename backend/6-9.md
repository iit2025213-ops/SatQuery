## PHASE 6: AOI SYSTEM

### Architecture

```
Frontend (React Map)
    ↓
Polygon Drawing & Editing
    ↓
GeoJSON Polygon
    ↓
POST /api/v1/aoi/validate
    ↓
Backend Validation
├─ Valid GeoJSON?
├─ Coordinates in [-180, 180] × [-90, 90]?
├─ Self-intersecting?
├─ Area within limits?
└─ Overlaps assets?
    ↓
AOI Saved to Job State
    ↓
Frontend Confirms
```

### Data Model

```
AOI Table (Supabase)
├─ aoi_id (UUID)
├─ job_id (FK)
├─ user_id (FK)
├─ geojson (JSONB)
├─ bbox (array[4])  -- [minx, miny, maxx, maxy]
├─ area_km2 (float)
├─ crs (string)
├─ validation_status (string)
├─ created_at
└─ updated_at
```

### Endpoints

```
POST   /api/v1/aoi/validate
       Body: { geojson, crs (optional) }
       Response: { valid, area_km2, bbox, errors[] }

GET    /api/v1/aoi/{aoi_id}
       Response: { aoi, metadata }

POST   /api/v1/aoi/from-bounds
       Body: { minx, miny, maxx, maxy }
       Response: { geojson, area_km2 }

POST   /api/v1/aoi/intersection
       Body: { aoi1, aoi2 }
       Response: { intersection_geojson, overlap_percent }

GET    /api/v1/aoi/bounds-check
       Query: asset_ids, aoi
       Response: { overlapping_assets[], non_overlapping[] }
```

### Capabilities

```
validate_aoi
├─ GeoJSON validation
├─ Coordinate bounds check
└─ Self-intersection detection

calculate_aoi_area
├─ Area in m²
├─ Area in km²
└─ CRS conversion

check_asset_overlap
├─ AOI overlaps with asset?
└─ Overlap percentage

clip_asset_to_aoi
├─ Crop asset to AOI bounds
└─ Generate clipped imagery
```

### Error Handling

```
Invalid GeoJSON
    ↓ Validation Error

AOI outside valid bounds [-180, 180]
    ↓ Bounds Error

AOI > 1,000 km²
    ↓ Size Limit Error

No assets overlap with AOI
    ↓ Coverage Warning

Self-intersecting polygon
    ↓ Geometry Error
```

## PHASE 7: GEE/STAC DATA LAYER

### Architecture

```
User Query
    ↓
AOI + Temporal Range
    ↓
GEE/STAC Connector
    ├─ Authenticate to GEE (service account)
    ├─ Authenticate to STAC catalog
    └─ Query satellite collections
        ↓
    ┌─ Sentinel-2 Collection
    ├─ Landsat-8/9 Collection
    ├─ MODIS Collection
    └─ Optional: Planet Labs, Maxar
        ↓
    Apply Filters:
    ├─ Spatial (AOI bounds)
    ├─ Temporal (user date range)
    ├─ Cloud cover (< 20% default)
    └─ Data quality
        ↓
    Retrieve Imagery Metadata
    ├─ Band info
    ├─ Resolution
    ├─ CRS
    └─ Acquisition date
        ↓
    Download Imagery
    ├─ Cloud-masked
    ├─ Normalized
    └─ Clipped to AOI
        ↓
    Store to Cloudinary
        ↓
    Create Asset Records (Supabase)
```

### Data Model

```
GEE Collection Table
├─ collection_id (UUID)
├─ job_id (FK)
├─ user_id (FK)
├─ collection_name (Sentinel-2, Landsat-8, etc)
├─ query_params (JSONB)
│   ├─ aoi
│   ├─ date_start
│   ├─ date_end
│   ├─ cloud_cover_max
│   └─ collection_filter
├─ results_count (int)
├─ metadata (JSONB)
│   ├─ total_results
│   ├─ filtered_results
│   └─ error_messages
├─ status (queued, running, completed, failed)
├─ created_at
└─ updated_at

GEE Asset Table
├─ gee_asset_id (string)
├─ collection_id (FK)
├─ source (Sentinel-2, Landsat, MODIS)
├─ acquisition_date (date)
├─ cloud_cover_percent (float)
├─ crs (EPSG code)
├─ resolution (m)
├─ bands (JSONB)
├─ cloudinary_url (string)
├─ status (ready, processing, failed)
└─ created_at
```

### Endpoints

```
POST   /api/v1/gee/query-imagery
       Body: {
         aoi,
         date_start,
         date_end,
         collections: ["Sentinel-2", "Landsat-8"],
         cloud_cover_max: 20,
         resolution_m: 10
       }
       Response: { collection_id, job_id, status }

GET    /api/v1/gee/collections/{collection_id}
       Response: { collection, imagery[], metadata }

GET    /api/v1/gee/imagery/{imagery_id}
       Response: { imagery, bands, url, metadata }

GET    /api/v1/gee/query-status/{collection_id}
       Response: { status, progress, retrieved_count, error }

POST   /api/v1/gee/retrieve-dem
       Body: { aoi, resolution_m (optional) }
       Response: { dem_id, dem_url, status }
```

    │   ├─ DEM + Satellite Texture
    │   ├─ Hillshade generation

# app/terrain/processor.py

class TerrainProcessor:
    """Process DEM and imagery into terrain visualizations"""
    
    async def generate_2d_terrain(self, dem_url, satellite_url, aoi_geojson):
        """
        Generate 2D terrain visualization
        
        Steps:
        1. Download DEM
        2. Download satellite imagery
        3. Clip both to AOI
        4. Generate hillshade
        5. Generate contours
        6. Overlay on satellite
        7. Upload to Cloudinary
        
        Returns: hillshade_url, contour_url, statistics
        """
    
    async def generate_3d_terrain(self, dem_url, satellite_url, aoi_geojson, options):
        """
        Generate 3D terrain mesh
        
        Steps:
        1. Download DEM
        2. Download satellite imagery
        3. Clip both to AOI
        4. Generate mesh from DEM (using elevation as vertices)
        5. Apply satellite texture
        6. Export as glTF/GLB
        7. Upload to Cloudinary
        
        Options:
        - elevation_exaggeration (default: 1.0)
        - mesh_resolution (default: 512x512)
        - LOD (level of detail)
        
        Returns: mesh_url, texture_url, bounds, statistics
        """
    
    def calculate_statistics(self, dem_data):
        """Calculate terrain statistics"""
        return {
            "min_elevation": dem_data.min(),
            "max_elevation": dem_data.max(),
            "mean_elevation": dem_data.mean(),
            "slope_degrees": calculate_slope(dem_data),
            "aspect_degrees": calculate_aspect(dem_data)
        }
```

## PHASE 9: TEMPORAL TIMELINE

### Architecture

```
AOI + Date Range [2019-2025]
    ↓
GEE Query for each year
    ├─ 2019 Sentinel-2 imagery
    ├─ 2020 Sentinel-2 imagery
    ├─ 2021 Sentinel-2 imagery
    ├─ 2022 Sentinel-2 imagery
    ├─ 2023 Sentinel-2 imagery
    ├─ 2024 Sentinel-2 imagery
    └─ 2025 Sentinel-2 imagery (if available)
        ↓
Apply Filters:
├─ Cloud cover < 20%
├─ Best scene per year
└─ Consistent bands
        ↓
Retrieve + Process
├─ Download each scene
├─ Align to common grid
├─ Normalize radiometry
└─ Clip to AOI
        ↓
Store Timeline Artifacts
├─ Year-by-year URLs
├─ Metadata JSON
└─ Aligned imagery
        ↓
Frontend Timeline Slider
├─ Scrub through years
└─ Interactive display
```

### Data Model

```
Timeline Table
├─ timeline_id (UUID)
├─ job_id (FK)
├─ aoi_id (FK)
├─ date_start (date)
├─ date_end (date)
├─ year_count (int)
├─ imagery_collection (string)  -- Sentinel-2, Landsat
├─ status (queued, processing, completed, failed)

### Timeline Processing

```python
# app/timeline/processor.py

class TimelineProcessor:
    """Process multi-year satellite imagery"""
    
    async def retrieve_timeline(self, aoi_geojson, date_start, date_end, collection, cloud_cover_max):
        """
        Retrieve imagery for each year in range
        
        Steps:
        1. Determine year range
        2. For each year:
            a. Query GEE for best scene
            b. Filter by cloud cover
            c. Download imagery
            d. Align to reference grid
            e. Normalize radiometry
            f. Clip to AOI
            g. Upload to Cloudinary
        3. Create timeline metadata
        4. Store all URLs
        
        Returns: timeline_id, imagery_urls[], status
        """
    
    async def align_imagery(self, reference_image, target_image):
        """
        Spatially align all imagery to reference year
        
        Uses image registration:
        - Calculate transformation
        - Apply affine warp
        - Verify alignment
        
        Returns: aligned_image
        """
    
    async def normalize_radiometry(self, imagery_list):
        """
        Normalize reflectance across years
        
        Accounts for:
        - Different sensors (Landsat 7 vs 8 vs 9)
        - Different atmospheric conditions
        - Seasonal variation
        
        Returns: normalized_imagery[]
        """
    
    async def generate_animation(self, timeline_id, format="gif"):
        """
        Generate animated GIF or video of time series
        
        Returns: animation_url
        """
```

retrieve_temporal_imagery

align_imagery_stack

normalize_radiometry

generate_timelapse_animation
